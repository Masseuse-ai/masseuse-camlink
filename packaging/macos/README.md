# macOS icon

The masseuse.ai mark as a macOS icon for the connector: the brand's serif M
in white over its purple wave, the wave running between two electrode pads,
on the dark tile, laid out on Apple's app icon grid (the tile 824 of a 1024
canvas with a transparent margin, corners at 22.37 % of the tile).

| File | What |
| --- | --- |
| `masseuse-camlink.icns` | the iconset (16, 32, 128, 256 and 512 px, each with its `@2x`) folded by `iconutil`; each size rendered from the vector, not downsampled |
| `masseuse-camlink-icon-1024.png` | the 1024 px master, alpha outside the tile |

For an application bundle, `masseuse-camlink.icns` goes to
`Contents/Resources/` and `CFBundleIconFile` names it. For a disk image, the
same file copied to the volume root as `.VolumeIcon.icns` with the volume's
custom-icon attribute set (`SetFile -a C /Volumes/<name>`) gives the mounted
image the mark. Neither is produced by the release yet: the darwin
connector ships as a signed and notarized binary in a `tar.gz`
(`.goreleaser.yaml`); these files are here for the bundle or image to come.

Both are generated by the masseuse.ai brand build, which also writes the
site's icons from the same geometry, so they are not edited here: regenerate
there and copy. The letter is an outline of a Charis SIL glyph (SIL Open Font
License 1.1); rendered as an image it is not a font and carries no naming
obligation.
